TalentSphere FINAL Frontend

This package contains the source frontend. Runtime/private files are intentionally excluded: .env, node_modules, dist, caches.

Implemented:
- High School Assessment Center shows all High School assessments without profile-stream locking.
- Aptitude and Logical Reasoning are available to High School users. College/Professional technical assessments are not shown in High School.
- College Assessment Center exposes Common, Aptitude, Coding, DSA, Technical/Core CS and Career.
- Professional Assessment Center exposes Common, Technical, DSA and Situational.
- Every attempt remains 10 questions.
- Assessment Report reads latest saved backend results by assessment type.
- Final Guidance reads the same backend result history; no hard-coded five-assessment requirement.
- High School profile photo upload/change/remove UI is restored.
